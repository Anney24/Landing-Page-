# Landing Page Project

## 🚀 Overview  
A simple, responsive landing page built with **HTML** and **CSS**.  
The goal of this project was to showcase front-end development skills, including responsive layout, clean design, and semantic HTML.

## 💡 Motivation  
I built this landing page as part of my web development learning journey. It helped me practice converting a design concept into a working web page and improve my CSS skills, especially in layout and styling.

## 🧰 Tech Stack  
- HTML5  
- CSS3  
  

## 📐 Features  
- Fully responsive design (mobile, tablet, desktop)  
- Clean navigation menu  
- Well-structured semantic HTML  
- Simple but elegant styling  

## 🔧 How to Run Locally  
1. Clone the repo:  
   `git clone https://github.com/Anney24/Landing-Page-.git`  
2. Navigate into the project folder:  
   `cd Landing-Page-`  
3. Open `index.html` in your browser (you can just double-click the file)
